# GameHub

Единая платформа для геймеров: библиотека игр, отслеживание прогресса,
статистика и открытие новых игр. Подробности о продукте и архитектуре —
в [docs/](docs/README.md).

Стек: Next.js (App Router) + TypeScript + Tailwind CSS, PostgreSQL + Prisma,
NextAuth.js, RAWG API.

## Быстрый старт

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Скопируйте `.env.example` в `.env` и заполните:
   - `DATABASE_URL` — строка подключения к PostgreSQL;
   - `AUTH_SECRET` — сгенерировать: `npx auth secret`;
   - `RAWG_API_KEY` — бесплатный ключ на [rawg.io/apidocs](https://rawg.io/apidocs);
   - `BLOB_READ_WRITE_TOKEN` — токен Vercel Blob для загрузки аватаров
     (необязательно; без него загрузка аватара отключается).

3. Примените миграции:

   ```bash
   npm run prisma:migrate
   ```

4. Запустите dev-сервер:

   ```bash
   npm run dev
   ```

Приложение будет доступно на [http://localhost:3000](http://localhost:3000).

## Реализовано

### MVP (этап 1 из [roadmap](docs/06-roadmap.md))

- Регистрация и вход по email/паролю (F1)
- Личный профиль: ник, био, загрузка аватара (Vercel Blob) (F3)
- Поиск игр через RAWG с кэшированием в БД (F5)
- Добавление игры в библиотеку со статусом (F6)
- Прогресс: % прохождения, часы, приватные заметки, авто-даты
  начала/окончания при смене статуса (F7)
- Оценка игры (F8)
- Статистика аккаунта: игры по статусам, часы, любимый жанр (F9)
- Каталог игр с фильтрами по жанру/платформе (F18); страница игры
  показывает расширенные данные RAWG (Metacritic, рейтинг сообщества,
  разработчик/издатель, ESRB, время прохождения, сайт, галерея
  скриншотов — до 6)
- Переключатель языка интерфейса RU/EN (хранится в cookie, см. `src/i18n/`)
- Интерфейс только в тёмной теме (см. [docs/07-open-questions.md](docs/07-open-questions.md))

### Социальный слой (этап 2, частично)

- Поиск пользователей на `/users` — по `@нику`, имени или короткому ID;
  у каждого пользователя есть числовой `publicId` (ссылка `/u/<число>`) (F13)
- Односторонние подписки и взаимные друзья (запрос → принятие) (F13)
- Публичные профили `/u/[username]` — библиотека и статистика (F13)
- Хаб связей `/friends`: входящие/исходящие запросы, друзья, подписки, подписчики
- Лента активности `/feed`: события друзей и подписок — добавил игру,
  начал играть, прошёл, оценил, написал отзыв, получил достижение (F14)
- Отзывы на игры: оценка 1–10 + текст, один на игру, на странице игры (F15)
- Достижения GameHub: 40 бейджей, открываются по действиям с библиотекой
  и отзывами, видны в профиле (F12)
- Приватность профиля: PUBLIC / PRIVATE (F4, базовая версия)
- Коллекции игр (`/collections`): создание, редактирование, удаление подборок,
  добавление игр из своей библиотеки (F10). Коллекции пока приватные —
  видны только владельцу.

Всё вышеперечисленное, включая поиск и добавление игр через RAWG,
проверено вручную end-to-end с реальным ключом и реальной PostgreSQL.
Без `RAWG_API_KEY` страница `/games` и поиск игр в библиотеке
недоступны — остальной функционал (аккаунт, профиль) работает
независимо от ключа. Названия жанров/платформ из RAWG всегда на
английском независимо от выбранного языка интерфейса — так их отдаёт
сам RAWG. Загрузка аватара проверена в части UI и деградации без токена;
полный цикл загрузки в Vercel Blob требует `BLOB_READ_WRITE_TOKEN`.
