# GameHub

Единая платформа для геймеров: библиотека игр, отслеживание прогресса,
статистика и открытие новых игр. Подробности о продукте и архитектуре —
в [docs/](docs/README.md).

Стек: Next.js (App Router) + TypeScript + Tailwind CSS, PostgreSQL + Prisma,
NextAuth.js, RAWG API.

## Быстрый старт

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Скопируйте `.env.example` в `.env` и заполните:
   - `DATABASE_URL` — строка подключения к PostgreSQL;
   - `AUTH_SECRET` — сгенерировать: `npx auth secret`;
   - `RAWG_API_KEY` — бесплатный ключ на [rawg.io/apidocs](https://rawg.io/apidocs).

3. Примените миграции:

   ```bash
   npm run prisma:migrate
   ```

4. Запустите dev-сервер:

   ```bash
   npm run dev
   ```

Приложение будет доступно на [http://localhost:3000](http://localhost:3000).

## Реализовано (MVP, этап 1 из [roadmap](docs/06-roadmap.md))

- Регистрация и вход по email/паролю (F1)
- Личный профиль (F3)
- Поиск игр через RAWG с кэшированием в БД (F5)
- Добавление игры в библиотеку со статусом (F6)
- Прогресс: % прохождения и часы (F7)
- Оценка игры (F8)
- Статистика аккаунта: игры по статусам, часы, любимый жанр (F9)
- Каталог игр с фильтрами по жанру/платформе (F18)
- Переключатель языка интерфейса RU/EN (хранится в cookie, см. `src/i18n/`)

Без RAWG_API_KEY страница `/games` и поиск игр в библиотеке недоступны —
остальной функционал (аккаунт, профиль) работает независимо от ключа.
Названия жанров/платформ из RAWG всегда на английском независимо от
выбранного языка интерфейса — так их отдаёт сам RAWG.
