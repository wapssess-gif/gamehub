# Roadmap

Этапы соответствуют приоритетам из [02-requirements.md](02-requirements.md)
(M → S → C). Даты не фиксируем (pet-проект) — важен порядок, а не сроки.

## Этап 0 — Подготовка

- Финализировать открытые вопросы ([07-open-questions.md](07-open-questions.md)).
- Выбрать стек (см. рекомендацию в [05-architecture.md](05-architecture.md)).
- Получить доступ к внешнему API (RAWG API key или IGDB/Twitch app).
- Настроить репозиторий, базовый CI (lint + тесты), окружение (.env).

## Этап 1 — MVP (функции M)

Цель: пользователь может завести аккаунт, найти игру, добавить в
библиотеку, отслеживать прогресс и видеть статистику.

- Регистрация/вход (email + пароль) — F1
- Личный профиль — F3
- Поиск игр через внешнее API + кэш в `Game` — F5
- Добавление в библиотеку со статусом — F6
- Прогресс (% / часы) — F7
- Оценка игры — F8
- Статистика аккаунта — F9
- Каталог/поиск с фильтрами по жанру/платформе — F18

Критерий готовности этапа — см. "Definition of Done" в
[03-user-stories.md](03-user-stories.md).

## Этап 2 — Социальный слой (функции S)

- OAuth-вход (Google/Steam) — F2
- Друзья (запрос/принятие) — F13
- Лента активности друзей — F14
- Отзывы (текст + оценка) — F15
- Коллекции игр — F10
- Топы/подборки по рейтингу комьюнити — F20

## Этап 3 — Обогащение и геймификация (функции C)

- Скриншоты в отзывах — F17
- Достижения из внешнего API (если источник это поддерживает) — F11
- Внутренние достижения GameHub — F12
- Лайки/комментарии к отзывам — F16
- Настройки приватности профиля — F4
- Рекомендации игр на основе библиотеки/оценок — F19

## Явно не планируется в этой версии продукта

- Модерация/жалобы как отдельная система (только заделы в схеме).
- Мобильное приложение.
- Монетизация (см. открытые вопросы — статус не определён).

## Как читать этот roadmap

Каждый этап — самостоятельно демонстрируемый прирост ценности: после
этапа 1 уже есть работающий личный трекер игр, даже без единого
друга или отзыва. Этапы 2 и 3 можно менять местами или частично
совмещать в зависимости от того, что интереснее делать в первую
очередь.
