# GameHub — документация проекта

Единая платформа для геймеров: библиотека игр, отслеживание прогресса,
статистика, отзывы и активность друзей.

Это учебный/pet-проект. Документация ниже описывает цели, требования,
модель данных и архитектуру, зафиксированные **до** написания кода —
так, чтобы сначала договориться о том, что и как строим. По мере
реализации разделы (особенно roadmap и открытые вопросы) обновляются,
чтобы отражать текущее состояние.
